# Trae MTC Multi-Format Showcase

## Purpose

A showcase of Trae SOLO MTC (More Than Code) work through an Excel model, PowerPoint presentation and interactive HTML dashboard, with existing artifacts available to download and read.

## Repository guide

| Entry | Contents |
| --- | --- |
| [Excel model](MTC_复杂Excel模型.xlsx) | Linked worksheets and dropdown controls |
| [Demonstration deck](MTC_能力演示.pptx) | Existing PowerPoint artifact |
| [HTML dashboard](interactive/3D_可交互销售仪表盘.html) | Interactive 3D presentation entry |
| [Operating notes](00_README.md) | Excel locations and Office for Mac hyperlink notes |
| [Development notes](README_DEV.md) | Model structure, implementation background and future directions |
| [Artifact previews](作品渲染图/) | Stored previews across formats |

## Getting started

1. Open the workbook’s `Analysis` sheet in Excel. Region, scenario and product controls are at B3, B4 and D3 respectively.
2. Open the deck in PowerPoint to view the existing slides.
3. Download the repository with its directory structure intact and open the HTML dashboard in a browser; relative resources are held in `assets/`.

## Scope and limitations

- This is an artifact repository without automatic build scripts or a standalone release.
- Office platform and version affect interactions; see `00_README.md` for Mac file-hyperlink differences.
- Demonstrated capabilities belong to these artifacts and do not guarantee Trae or other tools across all tasks and versions.
